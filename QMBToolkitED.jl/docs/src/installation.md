# Installation

Since this package is currently private, you need to install it directly from its GitHub repository.

Open the Julia REPL and use `Pkg` to add the package by URL:

```julia
using Pkg
Pkg.add(url="git@github.com:QMBToolkit/QMBToolkitED.jl.git")
```

If you are prompted for credentials, you will need to provide your GitHub username and a [Personal Access Token (PAT)](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens) with the `repo` scope.
